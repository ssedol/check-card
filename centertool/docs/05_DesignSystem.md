# 센터툴 (CenterTool) — Design System
> 프로젝트명: 센터툴 (CenterTool) | 버전: v1.0 | 생성일: 2026-06-09 KST  
> 작성 기준: 물리 CENTER TOOL 디자인 재현, 아이콘 중심 UI, SSOT 연결

---

## 디자인 철학

> **"물리 측정 도구를 화면 위로"**  
> 물리 CENTER TOOL의 공업용 측정 도구 느낌을 디지털로 재현한다.  
> 검정 배경 + 주황 격자 + 최소 텍스트 + 아이콘 중심 UI.

---

## 1. 컬러 시스템

| 역할 | 이름 | 색상값 | 사용처 |
|------|------|--------|--------|
| Background | Pure Black | `#000000` | 앱 전체 배경, 카메라 외부 영역 |
| Grid Primary | Tool Orange | `#FF6B00` | 격자 주선, L자 가이드, 코너 마커 |
| Grid Secondary | Tool Orange Dim | `#FF6B0099` | 보조 격자선, 눈금 숫자 |
| Grid Subtle | Tool Orange Ghost | `#FF6B0033` | Lv.3 고밀도 격자 배경선 |
| Surface | Dark Surface | `#1A1A1A` | 하단 컨트롤 바, 배너 영역 배경 |
| Icon Default | White | `#FFFFFF` | 아이콘 기본 상태 |
| Icon Active | Tool Orange | `#FF6B00` | 아이콘/버튼 활성 상태 |

| Feedback Error | System Red | `#FF3B30` | 에러 토스트 |

## 2. 타이포그래피

텍스트는 최소화. 격자 눈금 숫자와 시스템 알림에만 사용.

| 용도 | 폰트 | 크기 | 굵기 | 색상 |
|------|------|------|------|------|
| 격자 눈금 숫자 | 시스템 모노스페이스 | 10px | Regular | `#FF6B0099` |
| 레벨 버튼 레이블 | 시스템 기본 | 12px | Medium | `#555555` (비활성) / `#FF6B00` (활성) |
| 토스트 메시지 | 시스템 기본 | 14px | Medium | `#FFFFFF` |
| 권한 안내 문구 | 시스템 기본 | 16px | Regular | `#FFFFFF` |

## 3. 격자 레벨 스펙 (FEAT-1)

| 레벨 | 이름 | 셀 크기 | 선 굵기 | 투명도 | 용도 |
|------|------|--------|--------|--------|------|
| Lv.1 | 성긴 격자 | 40px | 1px | 70% | 빠른 대략 확인 |
| Lv.2 | 중간 격자 | 20px | 1px | 70% | 기본값, 일반 사용 |
| Lv.3 | 촘촘한 격자 | 8px | 0.5px | 60% | 정밀 측정 |

> 물리 CENTER TOOL보다 최대 5배 촘촘한 격자 제공 (Lv.3 기준)

## 6. 화면 레이아웃 구조

```
┌─────────────────────────────┐  ← 상단 Safe Area (iOS 노치/다이나믹 아일랜드)
│                             │
│                             │
│      카메라 풀스크린         │
│   ┌──────────────────────┐  │
│   │  ┘            └      │  │  ← FEAT-2: L자 코너 가이드 (4개)
│   │                      │  │
│   │      [ + ]           │  │  ← FEAT-2: 중앙 십자선 + 원
│   │   (격자 오버레이)     │  │  ← FEAT-1: Canvas 격자 레이어
│   │                      │  │
│   │  ┐            ┌      │  │  ← FEAT-2: L자 코너 가이드 (하단)
│   └──────────────────────┘  │
├─────────────────────────────┤  ← 컨트롤 바 (56px)
│  [L1] [L2] [L3]   ⬤ 캡처   │  ← 레벨 버튼 + 캡처 버튼
├─────────────────────────────┤  ← 광고 배너 (50px)
│         [ 광고 ]            │
└─────────────────────────────┘  ← 하단 Safe Area (홈 인디케이터)
```

> **중요:** L자 가이드 하단 코너는 컨트롤 바(56px) + 배너(50px) = 106px 위에 위치해야 한다.  
> 포켓몬 카드 비율 (63mm : 88mm = 약 5:7)에 맞게 가이드 영역을 계산한다.

## 7. 컴포넌트 명세

### 격자 레벨 버튼 (Level Button)

| 상태 | 배경 | 텍스트/아이콘 색상 | 테두리 |
|------|------|-----------------|--------|
| 기본 | 투명 | `#555555` | 없음 |
| 활성 (현재 선택됨) | `#FF6B0033` | `#FF6B00` | 1px solid `#FF6B00` |
| 탭 피드백 | `#FF6B0066` | `#FF6B00` | — |
| 크기 | 44px × 44px 이상 (터치 영역) | — | — |

### 캡처 버튼 (Capture Button)

| 상태 | 배경 | 아이콘 | 크기 |
|------|------|--------|------|
| 기본 | `#FFFFFF` | 카메라 아이콘 (검정) | 56px 원형 |
| 탭 피드백 | `#CCCCCC` | 카메라 아이콘 (검정) | 56px |
| 처리 중 (로딩) | `#AAAAAA` | 회전 애니메이션 | 56px |

### 토스트 알림 (Toast)

| 유형 | 배경 | 텍스트 | 위치 | 지속 시간 |
|------|------|--------|------|----------|
| 저장 성공 | `#00FF8820` | "저장됐어요 ✓" (`#00FF88`) | 화면 상단 중앙 | 2초 후 자동 사라짐 |
| 에러 | `#FF3B3020` | "다시 시도해요" (`#FF3B30`) | 화면 상단 중앙 | 3초 후 자동 사라짐 |

### 권한 안내 화면 (Permission Screen)

- 배경: `#000000` 전체 화면
- 중앙 상단: 카메라 아이콘 (흰색, 64px)
- 안내 문구: "센터툴은 카메라 접근이 필요해요" (흰색, 16px)
- 허용 버튼: 1px `#FF6B00` 테두리, 흰색 텍스트, 4px 라운드

### L자 코너 가이드 (FEAT-2)

- 변 길이: 48px
- 선 굵기: 3px
- 색상: `#FF6B00`
- 위치: 포켓몬 카드 비율(5:7)에 맞춘 4개 코너

### 중앙 십자선 (FEAT-2)

- 선 색상: `#FFFFFF`, 굵기 1px
- 선 길이: 화면 너비/높이의 각 10%
- 중앙 원: 반지름 8px, `#FFFFFF`, 빈 원형 (채우기 없음)

### 하단 컨트롤 바

- 배경: `#1A1A1A`
- 높이: 56px
- 상단 경계선: 1px `#FF6B0033`
- 내부 구성 (좌 → 우): `[L1]` `[L2]` `[L3]` 빈공간 `[캡처 버튼]`

## 8. 접근성 최소 패키지 체크리스트

| 항목 | 기준 | 상태 |
|------|------|------|
| 컬러 대비 (배경/아이콘) | WCAG AA 4.5:1 이상 | ✅ 검정 + 흰색 = 21:1 |
| 컬러 대비 (배경/주황) | WCAG AA 3:1 이상 (비텍스트) | ✅ `#FF6B00` on `#000000` = 3.4:1 |
| 포커스 링 | 키보드 탐색 시 주황 테두리 표시 | ✅ `outline: 2px solid #FF6B00` |
| 터치 타겟 최소 크기 | 44×44px 이상 | ✅ 모든 버튼 44px 이상 |
| 아이콘 버튼 레이블 | `aria-label` 속성 필수 | ✅ 각 버튼에 명시 필요 |
| 카메라 미사용 시 대체 | 권한 거부 시 안내 화면 | ✅ 설계됨 |
| 움직임 감소 선호 | 애니메이션 최소화 | ✅ 격자는 정적 렌더링 |
